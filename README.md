# Transformer Research

This repo uses [uv](https://docs.astral.sh/uv/getting-started/installation/).

You can open a browser-based jupyter notebook:  
`uv run jupyter lab`

Or if you want to use the vscode jupyter notebook editor, then you have to first run:  
`uv sync`  
And then the kernel should be available in the notebook's upper-right kernel selector.

Third option: [JupyterLite](https://jupyter.org/try-jupyter/lab/) is a way to run a lot of the code directly in your browser without installing/configuring anything.
